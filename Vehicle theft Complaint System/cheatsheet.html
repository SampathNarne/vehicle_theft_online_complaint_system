Overview

Project: Vehicle Theft Online Complaint System — register users, submit complaints, admin manages status.

Key files

Important patterns

Database helpers

connect_db(): returns sqlite3.Connection with dict-like rows, enables PRAGMA foreign_keys.

query_db(): parameterized queries, supports commit and fetching one vs many, rolls back on error.

Auth & Forms

Sessions store user_id, username, is_admin. Decorators protect routes.

WTForms defines forms and validators; Flask-WTF provides CSRF tokens.

Security checklist

  • Password hashing with bcrypt (use Argon2/passlib as alternatives).
  • Enable CSRF, use parameterized queries.
  • Set secure cookie flags and use server-side session store in production.
  • Sanitize/escape user content to prevent XSS; use CSP headers.
  • Rate-limit login attempts.
